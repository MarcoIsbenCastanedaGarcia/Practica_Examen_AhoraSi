# Prompt utilizado para desarrollar el proyecto

ESTE ES UN NUEVO PROYECTO

Contexto: Desarrollar un pequeño sistema web en donde exista un inicio de sesión, un registro, el sistema consiste en lo siguiente: Los usuarios se registran, inician sesión y pueden compartir notas, pensamientos y texto en general. También pueden visualizar los pensamientos, textos y demás de otras personas (algo tipo Substack). El diseño de las vistas e interfaces es conforme a la imagen adjunta que muestra el diagrama de las páginas.

STACK TECNOLÓGICO:

usaremos PHP, Laravel 13, css, JS y seguiremos la estructura de carpetas que crea el propio Laravel. Todo esto se hará con visual studio code, así que necesito me des el paso a paso de como crear mis carpetas del proyecto y el script para crear las bases de datos dentro de MariaDB.

De nuevo es por personas, así que necesito primero me hagas toda la parte del código para Frontend y luego toda la parte del código para Backend.

Así mismo necesito el script para crear el usuario y contraseña junto a toda la base de datos listo para copiarse y pegarse en MariaDB. Y claro su correcta conexión entre mi código la base de datos.

Lo mismo para los demás códigos, que me digas precisamente donde los copio y pego y los distintos comandos necesarios a ejecutar desde la terminal de VSC en caso de ser necesarios.

Dame todo esto en órden y paso a paso para no perderme. Además dime cómo crear las respectivas migraciones para nuestro proyecto.

Es importante recalcar esto:

NO uses emojis, en su lugar usa íconos SVG.

Que sea adaptable a pantallas de celular, pc, laptop, tabletas, etc.
