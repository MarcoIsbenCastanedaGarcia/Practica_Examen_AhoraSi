# FakeSTACK

FakeSTACK es un sistema web desarrollado como proyecto académico utilizando Laravel 13.

El sistema permite que los usuarios puedan:

- Crear una cuenta.
- Iniciar sesión.
- Cerrar sesión.
- Crear publicaciones.
- Compartir pensamientos, notas y textos.
- Visualizar las publicaciones de otros usuarios.

## Tecnologías utilizadas

- PHP 8.4
- Laravel 13
- MariaDB
- Blade
- CSS
- JavaScript
- Vite
- Composer
- Node.js
- npm

## Base de datos

El proyecto utiliza las siguientes tablas principales:

- `users`
- `posts`
